시스템 해킹이 주력이지만, AI도 공부해 두고 싶어 고른 기초 논문이다. 특히 "보안 도메인에 특화된 모델을 어떻게 싸게 만들까"라는 내 관심사와 맞닿아 있어 끌렸다. 논문을 읽고, PEFT로 직접 파인튜닝까지 돌려 본 기록을 함께 정리한다.

## 문제의식 — 전체 파인튜닝은 비싸다

GPT 같은 거대 모델을 특정 태스크에 맞추려면 보통 전체 파라미터를 다시 학습한다. 그런데 모델이 수억~수천억 파라미터면, 태스크마다 그만큼의 가중치를 새로 저장·학습해야 해서 비용과 저장 공간이 감당이 안 된다.

## 핵심 아이디어 — Low-Rank Adaptation

LoRA의 통찰은 "**파인튜닝으로 생기는 가중치 변화량 ΔW 는 사실 저차원(low-rank)이다**"는 가설이다. 그렇다면 ΔW 전체를 학습할 게 아니라, 두 개의 작은 행렬 곱으로 근사하면 된다.

```
W' = W + ΔW ≈ W + B·A
     ( B ∈ R^(d×r),  A ∈ R^(r×k),  r ≪ min(d,k) )
```

- 원래 가중치 `W` 는 **동결(frozen)** — 건드리지 않는다.
- 저랭크 행렬 `A`, `B` 만 학습한다. rank `r` 이 작으므로 학습 파라미터가 **수백 배 줄어든다.**
- 추론 시엔 `B·A` 를 `W` 에 더해 두면 되므로 **추가 지연도 없다.**

## 인상 깊었던 점

- **파인튜닝이 왜 필수인지가 명확해졌다**. 범용 모델은 언어 전반을 알지만, 보안 도메인의 언어 — CVE 서술 방식, 익스플로잇 코드 구조, CTF 라이트업 특유의 흐름 — 는 따로 가르쳐야 한다. 그리고 그걸 가르치는 데 **전체 파라미터를 다 건드릴 필요는 없다는 것**, 그게 직관적으로 와닿았다.
- `rank=4` 로도 성능이 유지된다는 실험 결과를 보고 나서야, "파인튜닝에서 배워야 할 정보는 생각보다 저차원에 있다"는 가설이 설득력 있게 느껴졌다. 처음엔 파라미터를 수백 배 줄이면서 성능이 유지된다는 게 솔직히 믿기 어려웠다.

## 직접 돌려본 실습 (PEFT)

말로만 이해하면 안 될 것 같아, `bloomz-560m` 에 PEFT로 LoRA를 붙여 돌려 봤다.

**`r=4` 설정의 효율이 수치로 와닿았다.**

| 항목 | 값 |
|------|-----|
| 전체 파라미터 | 559,607,808 |
| **학습 파라미터** | **393,216 (0.07%)** |
| frozen | 99.93% |

0.07%만 학습한다는 걸 숫자로 보니 LoRA의 효율이 실감났다. 학습 속도도 극적이었다.

| 환경 | 학습 시간 (epoch 2, 데이터 50개) |
|------|------|
| CPU | 1시간 이상 (중단) |
| GPU (T4) | 약 5초 |

다만 데이터가 50개뿐이라 `train_loss` 가 0.0으로 떨어지는 과적합이 났고, 기대한 지시-수행 결과도 제대로 안 나왔다. 출력이 이상해서 처음엔 CPU/GPU 혼용 문제인 줄 알고 입력 텐서를 `cuda` 로 옮기고, `do_sample`·`eos_token_id` 등을 바꿔 가며 트러블슈팅했다. (결국 데이터 양 자체가 원인에 가까웠다.)

```python
# 추론 입력을 모델 디바이스로 맞춰 준 부분
inputs = tokenizer("I want you to act as a motivational coach. ", return_tensors="pt")
inputs = {k: v.to(model.device) for k, v in inputs.items()}
```

> 실습에서 얻은 건 LoRA 이론보다도 "논문 결과를 재현하려면 데이터·환경 변수까지 다 맞아야 한다"는 감각이었다. 0.07%만 학습한다는 효율과, GPU 5초 vs CPU 1시간의 체감 차이는 글로만 읽었으면 안 남았을 것이다.

## 아쉬운 점

`rank` 선정 기준이 결국 실험적이라는 점이 걸렸다. 태스크 난이도나 데이터 양에 따라 적정 rank가 달라진다는데, 그걸 예측할 기준이 없다. 이걸 자동화하려는 후속 연구가 AdaLoRA라는 걸 알게 됐는데, 보안 도메인처럼 데이터 특성이 일반 NLP와 다른 경우엔 어떻게 작동할지 궁금하다.

## 정리

LoRA는 "적은 자원으로 거대 모델을 특정 도메인에 특화시키는" 길을 열어 준다. 내 관심으로 당겨 보면, **적은 비용으로 보안 특화 LLM**(CVE 분석·익스플로잇 이해·라이트업 생성 등)을 만들어 보는 그림과 바로 연결된다.
